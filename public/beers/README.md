# Beer logos

Only for beers better known than their brewery, such as Hop House 13 or Old Speckled Hen.
Everything else shows its brewery's logo from `../breweries/`.

Name the file after the beer's id in `seed/beers.json`, e.g. `old-speckled-hen.png`, square and
about 96 px. Nothing else to set: the file being here is enough.
